# Sports Database Management System

## Project Overview
The Sports Database Management System is an individual Advanced Database Management Systems (ADBMS) term project developed using MongoDB.

The project organizes sports-related information into multiple collections to demonstrate document-oriented database design, CRUD operations, queries, aggregation, and indexing.

## Database Details
- Database Name: MadhuDB
- Database Type: NoSQL
- Database Technology: MongoDB
- Tools: MongoDB Atlas and MongoDB Compass

## Collections
The database contains the following 10 collections:

1. Players
2. Teams
3. Coaches
4. Matches
5. Tournaments
6. Venues
7. Referees
8. Rankings
9. Sponsors
10. Player_Statistics

## Project Objectives
- Organize sports information in MongoDB collections.
- Perform CRUD operations.
- Execute filtering, sorting, and projection queries.
- Explore aggregation pipelines.
- Use indexes to improve query performance.
- Demonstrate relationships between collections where applicable.

## Technologies Used
- MongoDB
- MongoDB Atlas
- MongoDB Compass
- MongoDB Query Language (MQL)
